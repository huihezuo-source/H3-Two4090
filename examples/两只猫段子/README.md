# 示例：两只猫段子 第一期《回本那天》

公司 4090（ComfyUI 0.45.2 + H3 + H3 Image）上从零出的一期，14.5 秒，橘猫在左、蓝猫在右，老小区客厅沙发。完整做法和教训见 references/流程细节与教训.md 第 5、6、7 节。

| 文件 | 作用 |
|---|---|
| `gen_assets.sh` | H3 Image 文生图出 8 张数字资产：两猫头像、无头身体（近景、远景）、空客厅、手机。每张 2048×2048 或 1728×2368，4090 上约 1 分钟 |
| `提示词.md` | 资产和全景首帧的英文提示词（景别机位 → 环境 → 主体 → 动作 → 氛围 → 风格） |
| `h3_job_第一期.json` | H3 Ref2VA 任务：576×800、349 帧、20 步，参考图 = 全景首帧 + 两张头像，guides 是四个切镜点的首帧 |

步骤：
1. `gen_assets.sh` 出资产，原尺寸检查。
2. 全景首帧：`h3_image.py` 以空客厅为图 1、两张头像为图 2/3、远景无头身体为图 4/5 改图（提示词在 `提示词.md`）。
3. 单猫近景不要从全景裁：再用 `h3_image.py` 以全景 + 该猫头像生成，提示词写 centred、space above the ears、另一只猫 removed。
4. 把图片路径填进 `h3_job_第一期.json`，`h3_ref2va.py ... --wait` 出片；4 步 turbo 只当草稿，交付用 20 步。
5. whisper 核对台词，`speaker_grid.py` 逐句看嘴，再整片每秒 4 帧看一遍观感；lanczos 缩到 1080×1500，`post_subtitle_loud.py` 烧字幕调响度，`make_cover.py` 出封面。
