# 示例：把一条真人片原样做成动漫（人物认得出、原声全保留）

2026-11-13 在公司两台 4090 上跑通的一条 157 秒、69 个镜头的片子：人物全部改成动漫形象但一眼认得出是原来的演员，台词、配乐、音效用原片的，只换了一句广告词。方法和坑的总结在 `../../references/ComfyUI节点与参数.md` 的"原片整段动漫化"一节。

## 流程

1. **拆镜头**：`ffmpeg -vf "select='gt(scene,0.28)',showinfo"` 找切点，人工补漏，写成 `全片/shots.tsv`（镜头号、起、止、时长）；每个镜头抽第一帧到 `全片/原片帧/cNN.png`（裁掉黑边）。
2. **头像母版（先做，用户确认像本人再往下）**：每个角色从原片裁正脸到 `角色/原片脸/<名>.png`，`工程/角色母版.py <wj|xw> <角色名…>` 出 3 个种子的动漫头像（提示词里把演员的辨识特征逐条写死），拼图给用户挑，选定的存为 `角色/<名>_头像.png`。
3. **首帧**：`工程/首帧v2.py <wj|xw> <镜头号…|plain|faces>` 用 H3 Image 把每个原片帧原样转成动漫（3072×1312）。每个有人的镜头在 `EXPR` 里按原片写表情（平静的写平静、笑的写笑，只有真哭喊的写强烈）；`REFS` 写每个镜头带哪些头像母版；空镜在 `EXTRA` 里写"纯场景、无人"。两台机器分开跑，已存在的跳过。
4. **补锚定帧**：scene 检测漏掉的切点和 >5 秒长镜头的中段，用 `工程/补锚帧.py` 从原片抽帧转动漫（参考视频模式下没锚定的切点会整段变实拍）。找漏切点：帧差 + 直方图差列候选，每个候选前后两帧并排人工确认。
5. **确认首帧**：拼总览图给用户看，确认前不生成视频。
6. **声音**：`ffmpeg -i 原片.mp4 -vn 声音/原片音轨.wav`，按段切成 `声音/seg_X.wav`。要换台词的话：Mac 上 `pip install voxcpm demucs`，用这个角色的原片参考音续写克隆新词，`工程/配音合成.py` 把那几秒换成 demucs 分出的配乐 + 新词，并重切相关段的 seg_X.wav。
7. **视频**：`USE_REF=1 GEN_STEPS=20 FARM_OUT=farm_ref 工程/分段v2.py run`：原片对应片段当参考视频（动作、切镜、口型时机跟原片）+ 每切点锚定动漫首帧 + 整段原声锁第 0 帧，20 步（4 步 turbo 的帧间抖动高 15–33%，用户一眼看出"断档"），farm.py 分给两台机器。**每段不超过 250 帧（约 10 秒）**，再长显存溢出每步慢十倍；长段按真实切点拆，没有切点的长镜头补中段锚帧拆开、拼接时溶接 0.25 秒（`成片v2.py` 的 BLEND）。`分段v2.py one xw H` 单段重跑；`SEED_BASE=700` 换种子。同一位置反复出错就把段在那里拆开（E → E + E2）；镜头中段反复插全景的，拆到那段提示词里没有全景描述为止；临近切点提前切的，段尾多生成 0.5 秒并把下一镜锚在真实切点上。锚帧表里 cut/mid 要按机位是否真换来标，闪白不是切点。
8. **检查每段**：4 fps 总览对切点和构图；`strips_clip.py <mp4> <起始秒> <目录>` 出每个人 8 fps 嘴部条带，对照台词表看谁张嘴、没台词时嘴是否乱动；远景和原片同区域并排。
9. **整片检查**：`工程/成片检查.sh 拼接_草稿.mp4`：`嘴动对人声.py` 自动报"嘴动但台词表里没人说话"的时段（再人工看条带），2 fps 总览过一遍。
10. **成片**：`工程/成片v2.py join`（按原片时间线拼，纯道具镜头直接用原片）→ `upscale`（XW 上 ReCaVSR）→ `final`（1920×1080 宽银幕、字幕、标签、响度 -14）。标签位置和字幕时间在 `标签与字幕表.md`。

## 目录

```
工程/        脚本（H3_SCRIPTS 指到本仓库 scripts；YUNET 指到 yunet.onnx）：首帧v2、角色母版、补锚帧、分段v2、成片v2、配音合成、嘴动对人声、strips_clip、全流程.sh、成片检查.sh
首帧/原始/   动漫首帧 3072×1312（cNN.png 和补锚 cNN_秒.png）     首帧/生成尺寸/  1056×448
角色/        原片脸/、候选/、<名>_头像.png
声音/        原片音轨、各段 seg_X.wav、克隆的新词
生成/farm/   各段视频            成片/
```

脚本里的台词表、分段表、标签表都是这条片子的，换片子要重写。
