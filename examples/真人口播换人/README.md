# 真人口播换人：把原片里的主播整个换成 AI 角色（Ref2VA + Character Swap LoRA）

2026-11-16～18，公司两台 4090（XW/WJ，24 GB）实做。原片是 15 秒手机自拍口播（720×1280、24 fps、361 帧），目标：整个人换成另一个角色、声音同步换、牙齿自然、背景和运镜跟原片一致，看起来像手机实拍。

## 流程
1. `出形象.py`：H3 Image 以原片一帧（灰椭圆遮脸）当 `<Picture 1>` 出 6 个全身候选，人直接站在原片场景里，色调天然一致；用户挑。
2. `出露齿参考.py`：对选中形象出「说话露齿」半身照（在定稿图上只改一次，不反复改脸）。
3. 声音：先用声音设计出一段参考音（成年女声 200–300 Hz），H3 按 `<Audio 1>` 的音色自己合成台词并对口型。**参考音的文本不能含台词后半句**（会漏词，见教训）。
4. `做换人_公司.py <1|2|3> <xw|wj>`：Ref2VA，`body_swap:` 提示词 + Character Swap LoRA，`<Video 1>` 用去字幕的原片（缩到生成尺寸），**只带一张**「说话露齿」半身照当 `<Picture 1>`，`GEN_TURBO=1` 4 步、512×896、362 帧。`调度_正式版.py` 盯两台机器队列自动投放。
5. 检查（每条必做）：`闪回检测.py 出片.mp4 --src 原片.mp4`（整帧跳变 + 背景跳切，对照原片）、`牙齿检查.py`（每 2 帧嘴部拼图）、`scripts/asr.py` 台词逐字对照、librosa 音高。
6. `后期_公司.py`：补帧（`补帧.py`，DIS 光流）→ ReCaVSR 1.5× → 眼球微动 → 手机质感 720×1280 → 响度 −14 LUFS。

## 关键教训（逐步记录见 经验记录.md）
- **参考音会漏词**：参考音里念的词会被带进生成语音。参考音念着同一段台词时，五次出片都在同一句念乱；裁掉后半句后逐字正确。
- **只带一张参考图**：三张参考图（哪怕缩小）会把 24 GB 撑爆（5220 s/步）；身份、衣服、牙齿合成到一张里。
- **非 turbo 20 步跑不动**（停在 Model Initializing），4 步 turbo 正常；交付走 4 步 + ReCaVSR。
- **检测器报警必须对照原片**：背景“秒切”曾被当成快速转头放过，用户一眼看出。原片同帧连续＝生成缺陷，重出。
- **投任务前看显卡有没有被别的程序占着**；隧道掉线用 `RustDesk --port-forward <ID>` 恢复；日志里 `Failed to access remote 127.0.0.1:8188`＝对面 ComfyUI 没启动。

## 用时
每条 4 步生成 9–16 分钟 + 后期约 4 分钟（机器空闲时）。
