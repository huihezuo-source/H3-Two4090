# 股民的晚餐（2026-11-15）：参考片仿做 + 镜像反差版

两条 15 秒 9:16 短片《买A股股民的晚餐》《买美股股民的晚餐》，仿一条豆包生成的参考片（土灶素面、灯泡熄灭），再做一条豪宅龙虾的镜像反差版，外加 30 秒对比版。从拆参考片到三条交付 1 小时 25 分（两台公司 4090）。

流程：`出首帧.py --mode ref`（H3 Image 拿参考片的帧当 <Picture 1>，锁构图和色调；美股版用同一帧做镜像构图）→ 用户确认 8 张首帧 → `做视频.py`（每条一次生成 362 帧 448×800，首帧锚第 0 帧，切点帧和动作帧用 guides 锚定）→ 4 步草稿看动作 → 20 步正式 → `成片.py`（ReCaVSR 2.5× → 1080×1920 → 标题 → 响度）。

要点见 `工程/经验记录.md`：尺寸必须 32 的倍数；"皲裂的手"会画成丧尸；暗版首帧用程序压暗别用改图；草稿里偶然出现的好动作截帧当锚定帧；配乐要写 clearly audible。
